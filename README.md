# 琳浪小栈 — 情侣专属微信小程序

一个专为情侣打造的微信原生小程序，集商城点餐、恋爱日记、悄悄话、时光相册、心情打卡、纪念日、愿望清单、恋爱成就于一体。支持双端云同步，两个人的数据实时互通。

## 功能概览

| 模块 | 功能 |
|------|------|
| **首页** | 在一起天数、天气（季节模拟）+ 穿衣建议、每日情话、心情卡片、纪念日倒计时、消息红点提醒 |
| **商城** | 三级分类（食品/水果/其他）、爱心币点餐、帮我决定（随机选择）、许愿、订单管理 |
| **记录** | 恋爱日记、悄悄话（气泡聊天）、时光相册（云存储+评论+缩放预览）、心情打卡、愿望清单 |
| **我的** | 情侣头像、昵称管理、爱心币余额+交易记录、恋爱成就、纪念日管理、设置 |

## 核心设计

### 双角色体系
- **开发者**：通过密钥（默认 `langdev520`）进入。拥有商品管理、订单处理、发币/扣币、重置空间等权限
- **使用者**：通过邀请码绑定进入。购物、许愿、充值申请
- 角色不可切换，通过 `storage.getCurrentRole()` 判断

### 云同步架构
- 微信云开发（环境 `cloud1-d0gzs51l9cbf4b9bc`），NoSQL 数据库单文档存储
- 创建者输入密钥 → 设置信息 → 生成 6 位邀请码
- 加入者输入邀请码 → 绑定成功 → 双端数据实时同步
- 首页/商城每 5 秒、悄悄话每 3 秒自动轮询同步
- 断线恢复：网络故障保留本地绑定，邀请码本地缓存支持快速恢复

### 爱心币系统
- 使用者余额 `girl_coins`，双方可读取
- 开发者自由管理：增加/减少 + 留言，200 以上二次确认
- 交易记录 `coin_transactions` 存储历史
- 充值申请：使用者填写币数 + 交换条件 → 开发者审批

### 消息提醒系统
- `last_view_timestamps` 记录各模块最后查看时间
- 首页"今天想…"按钮和心情卡片显示红点
- 进入子页面自动清除对应红点

### 恋爱成就系统
- 4 等级：铜 7 / 银 11 / 金 6 / 铂 1，共 25 个成就
- `unlockAchievement(id)` 幂等解锁

## 技术说明

- 微信原生开发（WXML + WXSS + JS），无框架依赖
- 本地存储（wx.Storage）+ 微信云开发（NoSQL 数据库同步）
- 基础库 3.15.2，`es6: false`（关闭 Babel 转译）
- 天气使用纯本地季节模拟（utils/weather.js），无网络调用
- 300 句每日随机情话（utils/love-quotes.js）
- 禁止使用 wx.request / wx.getLocation（无权限）

## 快速开始

1. 克隆仓库
```bash
git clone https://github.com/LangTan1/WechatAppForCouple.git
```

2. 打开微信开发者工具 → 导入项目 → 选择目录

3. 修改 `project.config.json` 中的 `appid` 为你的小程序 AppID（或使用测试号）

4. 在微信开发者工具中开通云开发，环境 ID 与 `app.js` 中一致

5. 创建云数据库集合 `couples`

6. 编译运行

## 项目结构

```
├── app.js / app.json / app.wxss    # 全局入口与配置（4Tab：首页/商城/记录/我的）
├── utils/
│   ├── storage.js                  # 全部数据持久化 + 云同步（核心模块）
│   ├── weather.js                  # 纯本地季节天气
│   └── love-quotes.js              # 300 句每日情话
├── components/card/                # 公共卡片组件
└── pages/
    ├── setup/      # 访问控制（密钥验证 + 名字性别 + 邀请码绑定 + Pin 锁）
    ├── index/      # 首页：天数 + 天气 + 情话 + 心情 + 纪念日 + 红点
    ├── menu/       # 商城（双模式：使用者购物 / 开发者管理）
    ├── record/     # 记录入口（日记 / 悄悄话 / 相册 / 心情 / 更多）
    ├── profile/    # 我的：头像 + 信息 + 爱心币 + 成就 + 设置
    ├── diary/      # 恋爱日记
    ├── whisper/    # 悄悄话（气泡聊天，3 秒轮询）
    ├── album/      # 时光相册（云存储 + 评论 + 缩放预览）
    ├── anniversary/# 纪念日
    ├── wishlist/   # 愿望清单
    ├── mood/       # 每日心情打卡（5 种心情）
    └── achievement/# 恋爱成就（25 个成就 · 4 等级）
```
