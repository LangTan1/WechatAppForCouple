# 琳浪小栈 — 情侣专属微信小程序

一个专为情侣打造的微信原生小程序，集点餐、恋爱日记、时光相册、纪念日提醒、情话推送于一体。

## 功能概览

| 模块 | 功能 |
|------|------|
| **首页** | 在一起天数、天气（季节模拟）+ 穿衣建议、每日情话、纪念日倒计时提醒、快捷入口 |
| **菜单** | 双模式：使用者点餐（爱心币支付）+ 开发者管理（菜品上架/订单队列/请求处理） |
| **记录** | 恋爱日记、悄悄话（聊天气泡）、时光相册（二级结构） |
| **我的** | 情侣头像、昵称设置、爱心币管理、纪念日 CRUD、角色切换 |

## 核心设计

### 双角色体系
- **开发者（）**：通过开发者密钥进入，拥有菜单管理、订单处理、发币权限
- **使用者（）**：通过使用者密钥进入，点餐、许愿、充值申请
- 角色切换需密钥验证，界面不显示角色标签

### 菜单系统
- 使用者：分类浏览 → 爱心币点餐 → 订单追踪；许愿食物自动入队列
- 开发者：菜品管理 → 订单接受/拒绝（含原因）→ 标记完成；处理充值/食物请求
- 历史订单每 2 天自动清理，支持手动清除

### 时光相册
- 自定义相册（命名 + 描述）
- 照片可添加描述文字和日期
- 全屏预览，按时间排列

### 纪念日提醒
- 纪念日 CRUD，可设置"在一起日期"
- 首页 5 天倒计时提醒卡片

### 访问控制
- 首次使用需开发者密钥初始化
- 可选 4 位 PIN 应用锁
- 支持清除全部数据重新设置

## 技术说明

- 微信原生开发（WXML + WXSS + JS），无框架依赖
- 全本地存储（wx.Storage），无需后端
- 天气使用纯本地季节模拟，无需网络权限
- 300 句每日随机情话
- 卡片式布局 + 圆角 + 粉色系 UI
